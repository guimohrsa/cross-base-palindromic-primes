# Cross-Base Palindromic Primes

This repository contains the code and analysis for the sequence of primes that are:
1. Prime
2. Palindromic in base 10
3. Whose binary representation (read as decimal) is also prime
4. And also palindromic in base 10

## Sequence Found
a(1) = 3;
a(2) = 5; 
a(3) = 313;
a(4) = 7,284,717,174,827;

## Files
- `Heuristic Analysis of Cross-Base Palindromic Primes.pdf` - Complete heuristic analysis with integral convergence
- `prime_finder.py` - Optimized Miller-Rabin implementation
